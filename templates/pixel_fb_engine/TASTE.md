# TASTE.md — 《我落泪·情绪零碎》竖屏像素叙事 MV 美学宪法

## 1. 创作定位（Route & Aesthetic）
- **风格路线**：Claude/Opus 代码生成离散像素软件帧缓冲（`270×480` 逻辑画布 × `4` 最近邻无损放大至 `1080×1920`, `30fps`），融合 `claude-video-skills/pixel-art` 的 Indie Game 像素光影质感（Celeste / Eastward 级别选择性色调描边 + 4×4/8×8 有序 Bayer 抖动）与 `xigua-pixelmv` 的因果物理道具叙事。
- **核心情绪**：克制、孤独、雨夜破碎感与黎明释怀——从深夜室内微光，到暖色秋风回忆，到冰冷雨窗，到霓虹暴雨崩塌与风雪，最后于破晓天桥化为平静释放。
- **竖屏构图纪律（9:16 抖音友好）**：
  - 绝不裁切 16:9 横屏，从 `270×480` 原生重排版。
  - 视觉主体集中在垂直 `14%–72%` 黄金表演区；底部 `74%–84%` 专属保留给 `Zpix` 中文像素字幕牌（避开抖音底部文案栏 `bottom 15%` 与右侧互动图标 `right 14%` 遮挡）。
  - 零游戏 HUD：禁止出现 `STAGE / HP / BPM / SCORE` 等破坏电影感的 UI 框。

## 4. 反粗糙与反幻灯片红线（Anti-Slop Rules）
1. **严格整数像素纪律**：禁止 CSS 模糊放大、禁止浮点抗锯齿圆弧、禁止混用不同尺寸像素颗粒；全画布经 `Uint32Array` 软光栅输出并 `×4` 最近邻放大。
2. **静止段必须活着**：所有停顿帧必须保留雨丝、水洼涟漪、窗帘微摆、灯光呼吸、落叶或飘雪等真实微动态，绝不出现死帧（`dead_gap <= 1.0s`）。
3. **道具与动作因果闭环**：写诗→撕纸→碎页下落；封信→红章退信落桌；递还信束→女主转身走远（足底踩实地面，无漂浮滑步）；端杯→喝冷咖啡→放下接触阴影；伞脱手→流泪；触碰蔷薇→刺痛缩手→跪地崩溃；取出折纸→折纸飞机→迎风飞向朝阳。
4. **歌词与画面呼吸**：前奏与间奏留白隐去字幕条；歌词出现时使用本地 `Zpix` 像素点阵字库二值化描边渲染，逐字随演唱节奏轻弹亮起金色高光。
